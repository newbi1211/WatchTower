# WATCHTOWER · First Light v0.2

## 이번 버전

- 타이틀: 감시탑과 탐조등, 새 게임 / 이어하기 / 운영 지침, 저장 슬롯 표시. 타이틀에서는 시뮬레이션과 자동 저장을 실행하지 않습니다. 이어하기 시 부재 시간을 정산합니다.
- 채굴장 → 화물차 → 창고 원광 → 제련 생산. 가까운 창고와 차량 증차, 물류 지원 배치가 처리량에 영향을 줍니다. 물류 표시 버튼으로 연결과 이동 화물을 확인합니다.
- 반복 시간제 사고를 적재 누적과 설비 부담에 따른 사고로 전환. 감산·예방 정비·예비 냉각과 차량 증차로 대응합니다.
- 안전 우선 AI는 60초 후 응급 격리로 추가 손실만 막습니다. 수리와 원인 개선은 플레이어가 결정합니다.
- 주거 2칸 이내의 발전소·공장은 직원 피로를 높입니다. 김도윤은 수리 비용 감소 / 운송 속도 증가 / 연구 가속 중 하나를 지원합니다.
- 아르카 협력은 제련량 +25%, 성역회의 협력은 지속 식량 공급 증가. 자유상단 계약은 6분 이내 철강 120을 요구하며 식량 80과 차량 1대로 보상합니다.
- v0.1 저장을 유지하며 새 필드를 추가합니다. 변경된 생산 규칙은 이어하기부터 적용됩니다.

## 실행과 검증

Node.js 20 이상. 이 폴더에서 `npm start` 실행 후 http://127.0.0.1:4173 접속. `npm test`로 엔진과 타이틀 상태 전환 테스트 실행. 외부 패키지 설치 불필요.

## 조작

시설 클릭으로 조사. 하단 건물 선택 후 빈 구획에 배치. 중앙 5행/5열은 도로이므로 건설 불가. Esc로 취소. 물류 표시로 연결 확인. 오른쪽 관제 패널을 스크롤하여 운영 정책과 지원 업무 변경. 1× / 5× / 15×와 5분 부재 체험 제공. 브라우저 저장, 최대 30분 부재 정산.

## 구현의 한계

운송은 가장 가까운 창고와의 거리 기반 집계 모델입니다. 도로 경로 탐색·차량 충돌·개별 공장 재고는 아직 구현하지 않았습니다. 사람 이동은 표현용이며 개별 생활·관계 시스템은 없습니다. 감시탑은 건설까지만 지원합니다. 전투·영토 확장·협동 멀티플레이·서버 월드·전체 세력 정치는 후속 범위입니다. 현재 수치는 압축된 프로토타입용이며 장기 밸런스 검증이 필요합니다.
